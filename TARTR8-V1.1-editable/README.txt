TARTR8 V1.0 prototype
======================

Files:
- index.html  Main website
- styles.css  Visual identity and responsive layout
- script.js   Three playable games

Games:
1. Reaction — reaction-time test with local best score
2. Memory — sequence memory game with local best round
3. Number Rush — 30-second arithmetic challenge

Run:
Open index.html in a modern browser. No build system is required.

Note:
The contact email and any real business/social links are placeholders and should be replaced before publishing.
